## Task: Fix Runtime Error - Zod Compatibility Issue

**Date:** 2026-01-25
**Issue:** Setup minimal Tanstack Start app with auth protected routes and tailwind (#8)
**Commit:** 67d9210 - fix(web): upgrade Zod to v4.3.6 for Better Auth compatibility

### Problem
After deploying the TanStack Start app with Better Auth, the Lambda function was throwing a runtime error:
```
TypeError: z$1.coerce.boolean(...).meta is not a function
at file:///var/task/chunks/_/server-DkMexlIi.mjs:7042:44
```

### Root Cause
Better Auth 1.4.17 requires `zod@^4.3.5`, but the project was using `zod@^3.25.76`.

### Solution
Upgraded Zod from v3.25.76 to v4.3.6 in `packages/web/package.json`.

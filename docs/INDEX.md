# Vendor Docs Index

This directory stores snapshots of vendor documentation for quick offline reference.

- See `docs/VERSIONS.json` for snapshot metadata (version, source url, fetched at).
- Library folders under `docs/vendor/<lib>/` hold markdown snapshots.

Libraries targeted:
- TanStack Query, Router, Start, DB
- ElectricSQL
- SST
- Drizzle
- Better Auth
- Hono
- shadcn/ui
